An AI-powered application designed to analyze resumes against Job Descriptions (JD) using Natural Language Processing (NLP) to provide similarity scores, missing keywords, and actionable match feedback.

---

## 🌐 Live Web Application
👉 **[Click Here to Access Live App](https://ai-resume-jd-matcher-2shsblwb9sismuxmapy5dj.streamlit.app/)**

---

## 🚀 Key Features

* 📊 **Match Percentage:** Calculates exact relevance percentage between candidate resume and job description using **TF-IDF Vectorization** and **Cosine Similarity**.
* 🔍 **Keyword Gap Analysis:** Extracts and highlights missing technical skills and domain terms required to pass ATS filters.
* 📑 **Multi-Format Support:** Parse text directly or upload candidate resumes in standard **PDF format**.
* ⚙️ **Interactive UI:** Built using Streamlit with custom dark-slate high-contrast styling for enhanced user experience.

---

## 🛠️ Tech Stack

* **Language:** Python
* **Machine Learning / NLP:** Scikit-Learn (TF-IDF Vectorizer, Cosine Similarity)
* **Frontend / Web Framework:** Streamlit
* **Text Processing:** PyPDF2
